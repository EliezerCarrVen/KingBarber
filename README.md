KingBarber

Sistema de gestión de citas para barbería con selección de sucursal por geolocalización, pago en línea y roles diferenciados para Cliente, Barbero y Administrador.

Proyecto de residencia profesional — Instituto Tecnológico Superior de Lerdo (ITS Lerdo). Desarrollado en equipo bajo metodología Scrum.

🛠️ Stack tecnológico
Componente	Tecnología
Backend / API	TypeScript (Node.js + Express)
Apps (Cliente y Barbero)	Kotlin (Android)
Base de datos	MongoDB (local) / MongoDB Atlas (nube)
Pagos	PayPal Developer SDK
Versionamiento

Para evitar incompatibilidades entre entornos, todo el equipo trabaja con las mismas versiones:

Herramienta	Versión
Node.js	24.x LTS
TypeScript	6.0.x (fijado sin ^ en package.json)
Kotlin	2.2.x
Android Gradle Plugin (AGP)	9.2.x
JDK	17
Gradle	9.x

Requisitos previos
Git
Node.js 24.x LTS
Android Studio (JDK 17 incluido)
