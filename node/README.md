node — KingBarber API

Backend del proyecto KingBarber: sistema de gestión de citas para barbería con selección de sucursal por geolocalización, pago en línea y roles diferenciados para Cliente, Barbero y Administrador.

🛠️ Stack tecnológico
Componente	Tecnología
Backend / API	TypeScript (Node.js + Express)
Base de datos	MongoDB (local) / MongoDB Atlas (nube)
Pagos	PayPal Developer SDK
Versionamiento
Herramienta	Versión
Node.js	24.x LTS
TypeScript	6.0.x (fijado sin ^ en package.json)
Requisitos previos
Git
Node.js 24.x LTS
MongoDB Community Server (para desarrollo local)
